AgriShield API

This host serves the read-only HTTP API for the AgriShield parametric insurance contracts on Stellar testnet. It renders no interface — the operator console is a separate deployment.

  • GET /api/health — network, contract addresses, node reachability
  • GET /api/policies?farmer=G… or ?region=… — live policies
  • GET /api/settlements/… — what settlement would do right now

Every query reads the contracts directly, so the answers are the chain's, not a cache's. There is no settlement keeper here: a keeper is an interval that submits transactions, and a function has no life between requests to run one in. That is also why no signing key is configured on this host — it can read everything and move nothing.
